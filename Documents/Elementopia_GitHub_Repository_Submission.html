4. Core Modules & Refactored Capabilities (v2.0)

Module 1: Elemental Resonance Puzzle

  • Stoichiometric Synthesis: Drag-and-drop valence electron pairing to form ionic and covalent bonds.
  • Meaningful Byproduct Feedback: Real-time diagnostic alerts when an invalid mix yields real chemical compounds.
  • Hazmat Protocol Anti-Guessing: Sliding-window algorithm that temporarily locks workbench upon rapid spam clicking.
  • Two-Tier Educational Debrief: Explicit milestone reviews explaining polar/nonpolar covalent vs ionic transfer.

Module 2: Assessment & Progress

  • Automated Telemetry Sync: Asynchronous dispatch of pre-test baselines directly to Supabase cloud within < 2s.
  • Learning Gain Tracking: Automated calculation of Hake's normalized learning gain (g ≥ 0.40).
  • Visual Mastery Dashboard: Radar charts and progress indicators tracking student mastery of DepEd competencies.

Module 3: 1v1 Opponent Challenge

  • 5-Digit Room Matchmaking: Fast peer connection in < 5 seconds via WebSocket channels.
  • Synchronized Synthesis Race: Live sub-second race to synthesize target chemical compounds.
  • Heartbeat Disconnect Engine: 3s ping + 8s silence detector triggers 15s grace modal and clean forfeit win resolution.

Non-Functional Usability Standards

  • Mobile Touch Target Standards: Enforces ≥ 48px × 48px interactive boundaries across 360px–768px viewports.
  • Zero-Friction Access: Instant guest nickname onboarding without requiring email registration.

5. Local Development Quick-Start

# 1. Clone the verified repository:
git clone https://github.com/igoirshiy/Elementopia-Main.git
cd Elementopia-Main

# 2. Run the Frontend (React 19 + Vite):
cd Elementopia/FRONTEND
npm install
npm run dev                  # Serves on http://localhost:5173

# 3. Run the Backend (Spring Boot 3 + Java 17):
cd ../BACKEND
.\mvnw.cmd clean spring-boot:run   # Serves on http://localhost:8080
